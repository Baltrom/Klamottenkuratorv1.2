# Zehn Beispiel-Outfits für eure Präsentation

40 Kleidungsstücke; zehn vollständige Beispielkombinationen. Alle Werte entsprechen wardrobe.py.

## Laden ohne Neuinstallation

App schließen. clothing_curator_dataset.json aus diesem ZIP in den aktuellen Projektordner neben main.py, wardrobe.py und style.qss kopieren. Falls dort bereits eine gleichnamige Datei liegt, diese zuerst umbenennen, damit eure eigenen Daten erhalten bleiben. Danach im bisherigen Terminal:

```bash
python main.py
```

Beim Start liest die aktuelle App den Datensatz direkt aus dem Projektordner. Alternativ auf der Startseite „JSON-Kleiderschrank importieren“ anklicken; dann werden die Beispiele dem bisherigen Kleiderschrank hinzugefügt.

## Vorführen

Kleiderschrank öffnen → gewünschtes Zusatzteil wählen → Anlass und Jahreszeit wie unten auswählen → Outfit erstellen. Die App ergänzt Oberteil, Hose und Schuhe. Sie darf dabei auch zwischen den Beispielsets kombinieren; die Liste unten sind zehn kuratierte Beispiele, keine fest verdrahteten Vorschläge.

Alle Teile eines Sets haben denselben Anlass und dieselbe Jahreszeit. Mit dem jeweiligen Zusatzteil als Basis entstehen vierteilige Outfits. Wer stattdessen mit einem Oberteil beginnt, bekommt entsprechend dem aktuellen Prototyp zunächst drei Teile.
